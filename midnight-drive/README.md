# Midnight Drive

![Midnight Drive](preview.png)

비가 갠 도시의 한밤을 운전석에서 바라봅니다. 젖은 아스팔트의 빛 반사, 흐르는 차선과 유리 위 빗방울.

[ZIP 다운로드](https://github.com/aidevksh/WallpaperStore/releases/latest/download/midnight-drive.zip) · [전체 카탈로그](../README.md) · [WallpaperJS 릴리즈](https://github.com/aidevksh/WallpaperJS/releases)

## 사용법

WallpaperJS에서 이 폴더 또는 ZIP을 가져와 디스플레이에 적용하세요. 브라우저에서는 `index.html`을 열면 됩니다. HTML/CSS/JavaScript가 장면을 실시간으로 그리며, 외부 네트워크·이미지·폰트·오디오·동영상 파일이 필요하지 않습니다.

미리보기는 실제 렌더링을 캡처한 정지 이미지입니다. 기본 30fps, 최대 DPR 1.5로 동작하며 WallpaperJS의 30/60fps 및 일시정지, 숨겨진 페이지, 운영체제의 동작 줄이기 설정을 지원합니다. 16:9 기준으로 구성했으며 다른 화면 비율에서는 비율을 유지하면서 가장자리를 잘라 채웁니다.

## 제작 및 라이선스

로컬 `background.png`는 ImageGen으로 생성한 사실적인 운전석 원화입니다. 도시와 대시보드의 질감을 유지하며 JavaScript가 노면 흐름·차선·빗방울·빛의 변화를 실시간 합성합니다. [원화 생성 프롬프트](ARTWORK.md).
