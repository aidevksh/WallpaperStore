# Pixel Voyage

![Pixel Voyage](preview.png)

금빛 석양 아래 정교한 대항해시대 범선. 촘촘한 도트 구름과 넘실대는 파도, 흔들리는 배와 부서지는 포말.

[ZIP 다운로드](https://github.com/aidevksh/WallpaperStore/releases/latest/download/pixel-voyage.zip) · [전체 카탈로그](../README.md) · [WallpaperJS 릴리즈](https://github.com/aidevksh/WallpaperJS/releases)

## 사용법

WallpaperJS에서 이 폴더 또는 ZIP을 가져와 디스플레이에 적용하세요. 브라우저에서는 `index.html`을 열면 됩니다. HTML/CSS/JavaScript가 장면을 실시간으로 그리며, 외부 네트워크·이미지·폰트·오디오·동영상 파일이 필요하지 않습니다.

미리보기는 실제 렌더링을 캡처한 정지 이미지입니다. 기본 30fps, 최대 DPR 1.5로 동작하며 WallpaperJS의 30/60fps 및 일시정지, 숨겨진 페이지, 운영체제의 동작 줄이기 설정을 지원합니다. 16:9 기준으로 구성했으며 다른 화면 비율에서는 비율을 유지하면서 가장자리를 잘라 채웁니다.

## 제작 및 라이선스

`background.png`는 석양 바다 원화, `ship.png`는 실제 투명 배경의 범선 레이어입니다. 두 원화는 ImageGen으로 생성했습니다. 960×540 Canvas에서 보간 없이 합성하고, JavaScript가 파도·선체의 흔들림·포말·수면 반짝임·갈매기를 움직입니다. [원화 생성 프롬프트](ARTWORK.md).
