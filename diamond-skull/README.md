# Diamond Skull

![Diamond Skull](preview.png)

크리스탈과 다이아몬드로 빚은 해골. 보석의 면을 따라 흐르는 빛과 반짝이는 섬광.

[ZIP 다운로드](https://github.com/aidevksh/WallpaperStore/releases/latest/download/diamond-skull.zip) · [전체 카탈로그](../README.md) · [WallpaperJS 릴리즈](https://github.com/aidevksh/WallpaperJS/releases)

## 사용법

WallpaperJS에서 이 폴더 또는 ZIP을 가져와 디스플레이에 적용하세요. 브라우저에서는 `index.html`을 열면 됩니다. HTML/CSS/JavaScript가 장면을 실시간으로 그리며, 외부 네트워크·이미지·폰트·오디오·동영상 파일이 필요하지 않습니다.

미리보기는 실제 렌더링을 캡처한 정지 이미지입니다. 기본 30fps, 최대 DPR 1.5로 동작하며 WallpaperJS의 30/60fps 및 일시정지, 숨겨진 페이지, 운영체제의 동작 줄이기 설정을 지원합니다. 16:9 기준으로 구성했으며 다른 화면 비율에서는 비율을 유지하면서 가장자리를 잘라 채웁니다.

로컬 `background.png`는 ImageGen으로 만든 정지 원화입니다. 사실적인 크리스탈 굴절과 해골 형태를 바탕으로 `main.js`가 보석 면의 반짝임과 빛의 변화를 실시간 합성합니다. 동영상 재생은 사용하지 않습니다. [원화 생성 프롬프트](ARTWORK.md).
